- (decision) AD-2: Password hashing — bcrypt with default work factor; plaintext password must never persist or appear in responses. Binds: /register, /login. Prevents: plaintext credential storage.

- (decision) AD-4: JWT as sole auth mechanism — signed token in Authorization header; no refresh tokens, no session cookies. Binds: /me, middleware. Prevents: mixed auth strategies.
- (decision) AD-5: Error responses — consistent HTTP status codes + JSON body with detail field. Binds: all endpoints. Prevents: inconsistent error shapes across units.
